Pull Requests are welcome, please make sure they are human readable and reviewable
* don't mix functional and cosmetic changes or unrelated changes in the same commit
* each commit should be self contained all tools and tests should be fully working after each commit
* review each of your commits and run the whole test suite (`python -m unittest discover -s tests -b`) before submitting the PR
* bugfixes should come with a regression test using real data
* AI assistance may be used
